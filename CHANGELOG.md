# Changelog

## 2.2.0 — 24 Oktober 2026

Publikasi source dan paket demo; versi aplikasi Android tetap 2.2/versionCode 4.

- Toolchain Windows lokal dengan versi dan SHA-256 tetap.
- Mode demo geometris yang dapat dibagikan tanpa bundel artwork game.
- Panduan pemasangan, build, penggunaan, pemulihan, dan troubleshooting dengan screenshot asli.
- Installer ADB berparameter serial serta pencatatan HOME lama; tidak menghapus launcher OEM.
- GitHub Actions build/test dan 14 pemeriksaan logika.
- Guard foreground drawable untuk kompatibilitas API 21–22; perilaku perangkat API 27 tetap sama.

## Aplikasi 2.2 — 22 Oktober 2026

- 25 slot cover dan wallpaper, dengan mapping stabil dan unik hingga 25 aplikasi.
- Jam, navigasi ikon kotak, tombol Enter.
- Indikator GPS hijau/merah; drift 1–2 km/h ditekan menjadi 0.

## Aplikasi 2.1 — 22 Oktober 2026

- Panel GPS besar kanan bawah, status gerakan, panel aplikasi kecil.
- Navigasi kiri/kanan dan semua aplikasi dengan cover game.

## Aplikasi 1.0 — 22 Oktober 2026

- Launcher native awal untuk head unit TS7; favorit dasar dan daftar aplikasi.
