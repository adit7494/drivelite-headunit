# Artwork and tools

DriveLite source code, documentation text, and procedural demo artwork are licensed under MIT.

Game artwork belongs to its respective publishers. Game covers and wallpapers are **not committed to this repository or bundled in the public demo APK**. `assets/credits.json` records the original source URLs and checksums. The optional `download-assets.ps1` retrieves these images locally; those files remain ignored by Git. This project does not grant a license to redistribute the game images.

The screenshots in `docs/images/` illustrate the author's personal installation with optional game artwork. The visible artwork remains credited to the respective publishers. DriveLite is an independent launcher, not a Sony or PlayStation product.

Android SDK tools and Eclipse Temurin are downloaded from their official distributions and retain their own licenses:

- Android SDK: <https://developer.android.com/studio/terms>
- Eclipse Temurin: <https://adoptium.net/about>
- Complete game source list: [assets/credits.json](assets/credits.json)
