# Mulai dari HU, lalu lanjutkan bersama AI

Panduan utama sudah disusun berurutan di **[README — Mulai di sini](../README.md#mulai-di-sini)**:

1. Pastikan HU tipe TS7.
2. Buka dan aktifkan Developer options.
3. Aktifkan USB debugging.
4. Sambungkan HU dan PC ke Wi-Fi yang sama.
5. Aktifkan debugging Wi-Fi melalui Terminal HU.
6. Buka Claude, ChatGPT/Codex, atau Antigravity di PC.
7. Kirim isi **[MULAI-DENGAN-AI.txt](../MULAI-DENGAN-AI.txt)** dan ikuti percakapan AI.

File prompt langsung dipakai tanpa mengisi daftar aplikasi. AI akan menanyakan IP dan kebutuhan kalian, memeriksa perangkat, memberi rekomendasi, lalu mengurus build serta pemasangan launcher. Kalian memilih tindakan debloat setelah melihat hasil pemeriksaannya.
